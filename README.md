# 📖 Qalam Academy

Welcome to **Qalam Academy**, a full-stack educational web application designed for learning classical Arabic, Tajweed, Islamic jurisprudence (Fiqh), Sirah, and Creed (Aqidah). 

This repository contains both a responsive **Vite + React (TypeScript)** frontend and an **Express (TypeScript)** backend proxying AI-powered tutoring requests to the **Gemini 3.5 Flash** model.

---

## 🚀 Quick Start: Running Locally

Follow these steps to run Qalam Academy on your local computer.

### 1. Prerequisites
Ensure you have the following installed on your machine:
* **Node.js** (v18.x or higher recommended)
* **npm** (comes pre-packaged with Node.js)

### 2. Installation
Extract the files or clone this project, then open your terminal inside the project's root folder and run:
```bash
npm install
```

### 3. Environment Variables Setup
Copy the example environment file to create a local `.env` file:
```bash
cp .env.example .env
```

Open `.env` in your text editor and configure the following variables:
* **`GEMINI_API_KEY`**: Your API key from [Google AI Studio](https://aistudio.google.com/). This activates the real-time interactive AI Quran Tutor and custom questions generated by the Sheikhs.
* **`GOOGLE_MAPS_PLATFORM_KEY`**: (Optional) Your Google Maps API Key to render real interactive maps for locating mosques and Islamic centers around you.

### 4. Running the App

#### 🔹 Development Mode
To boot up both the Express server and Vite frontend simultaneously with automatic reload (HMR):
```bash
npm run dev
```
Once started, open your browser and navigate to:
👉 **`http://localhost:3000`**

#### 🔹 Production Build
To bundle the frontend application assets and compile the TypeScript backend into optimized JavaScript:
```bash
npm run build
```
This command compiles the Express backend into a single-file CJS bundle at `dist/server.cjs` and places static frontend files in `dist/`.

#### 🔹 Start Production Server
After building, launch the standalone production server:
```bash
npm run start
```

## 🗄️ Database Architecture & How to Connect a Database

Currently, the application runs on a lightweight, reactive **In-Memory Database State** declared in `server.ts` (using `const db = { ... }`). 

While this is incredibly fast for development, **any server restart or container scale-down will reset progress**. Below are practical guides to connect a real persistent database.

---

### Option A: Connecting Firebase Firestore (Recommended for Serverless/SPAs)

Firebase Firestore is a flexible NoSQL cloud database that integrates beautifully.

#### 1. Install Firebase Admin SDK
Run the following command to add Firebase Admin to the server:
```bash
npm install firebase-admin
```

#### 2. Configure Firebase Admin in `server.ts`
Create a service account in your Firebase Console, download the JSON key, and configure your backend. 

Add the following initialization at the top of your `server.ts`:

```typescript
import admin from "firebase-admin";

// Initialize Firebase Admin safely
const serviceAccount = process.env.FIREBASE_SERVICE_ACCOUNT_KEY 
  ? JSON.parse(process.env.FIREBASE_SERVICE_ACCOUNT_KEY) 
  : null;

if (serviceAccount) {
  admin.initializeApp({
    credential: admin.credential.cert(serviceAccount)
  });
} else {
  console.warn("⚠️ Firebase key missing. Defaulting to in-memory mode.");
}

const db = admin.apps.length ? admin.firestore() : null;
```

#### 3. Update API Endpoints to Fetch and Write to Firestore
Replace local state updates with Firestore calls. For example, updating the `/api/state` and `/api/lessons/complete` endpoints:

```typescript
// Fetch user progress & state
app.get("/api/state", async (req, res) => {
  if (!db) return res.json(inMemoryDbFallback);

  try {
    const userDoc = await db.collection("users").doc("default_student").get();
    if (userDoc.exists) {
      res.json(userDoc.data());
    } else {
      // Seed initial state if empty
      await db.collection("users").doc("default_student").set(inMemoryDbFallback);
      res.json(inMemoryDbFallback);
    }
  } catch (err) {
    res.status(500).json({ error: "Firestore error" });
  }
});

// Update completed lessons
app.post("/api/lessons/complete", async (req, res) => {
  const { lessonId } = req.body;
  if (!db) {
    // Fallback to local
    return res.json({ success: true, progress: localProgress });
  }

  try {
    const userRef = db.collection("users").doc("default_student");
    const userDoc = await userRef.get();
    const data = userDoc.data();

    if (data && !data.progress.completedLessons.includes(lessonId)) {
      const updatedLessons = [...data.progress.completedLessons, lessonId];
      const newPoints = data.progress.points + 25;
      const newHours = data.progress.hoursStudied + 0.5;

      await userRef.update({
        "progress.completedLessons": updatedLessons,
        "progress.points": newPoints,
        "progress.hoursStudied": newHours
      });
    }
    
    const updatedDoc = await userRef.get();
    res.json({ success: true, progress: updatedDoc.data()?.progress });
  } catch (err) {
    res.status(500).json({ error: "Failed to update progress" });
  }
});
```

### Option B: Connecting PostgreSQL (Relational Database)

If you prefer a relational SQL database, you can use **PostgreSQL** alongside an query builder or ORM such as **Prisma** or **Drizzle**.

#### 1. Install Prisma and PostgreSQL client
```bash
npm install @prisma/client
npm install prisma --save-dev
```

#### 2. Create your database schema (`prisma/schema.prisma`)
```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

model StudentProgress {
  id               String   @id @default("default_student")
  streakDays       Int      @default(3)
  hoursStudied     Float    @default(12.5)
  completedLessons String[] @default([])
  quizzesPassed    Int      @default(2)
  points           Int      @default(150)
}

model Course {
  id          String   @id
  category    String
  title       String
  description String
  level       String
  duration    String
}
```

#### 3. Initialize Prisma Client in `server.ts`
```typescript
import { PrismaClient } from "@prisma/client";
const prisma = new PrismaClient();
```

#### 4. Replace endpoints with SQL queries
```typescript
app.get("/api/state", async (req, res) => {
  try {
    const progress = await prisma.studentProgress.findUnique({
      where: { id: "default_student" }
    });
    
    // Serve courses, teachers, and current progress
    res.json({
      progress: progress || { streakDays: 3, hoursStudied: 12.5, completedLessons: [], quizzesPassed: 2, points: 150 },
      courses: PRESET_COURSES,
      teachers: PRESET_TEACHERS,
      subscription: { status: "free", plan: null, expiryDate: null }
    });
  } catch (error) {
    res.status(500).json({ error: "Database query failed" });
  }
});
```

### Option C: SQLite (Simple Persistent File)

For a fast local file-based database that requires zero database servers to run:

#### 1. Install SQLite3 driver or Better-SQLite3
```bash
npm install better-sqlite3
npm install --save-dev @types/better-sqlite3
```

#### 2. Initialize in `server.ts`
```typescript
import Database from "better-sqlite3";
const sqliteDb = new Database("qalam_academy.db");

// Bootstrap tables if they don't exist
sqliteDb.exec(`
  CREATE TABLE IF NOT EXISTS progress (
    id TEXT PRIMARY KEY,
    streak_days INTEGER,
    hours_studied REAL,
    points INTEGER
  );
  
  CREATE TABLE IF NOT EXISTS completed_lessons (
    student_id TEXT,
    lesson_id TEXT,
    PRIMARY KEY (student_id, lesson_id)
  );
`);
```

## 🛠️ Project Structure
* `/server.ts` - Express backend hosting API endpoints and routing client requests to Gemini AI.
* `/src` - React frontend application.
* `/src/App.tsx` - Main app entry point housing core state synchronization, page router, translation providers, and active layout components.
* `/src/components/` - Extracted sub-views (Dashboard, Courses, Classes/Teachers, Pratique/Qibla Map, Communaute/Forum, etc.).
* `/vite.config.ts` - Configuration setting up asset build pipelines and proxy maps.
